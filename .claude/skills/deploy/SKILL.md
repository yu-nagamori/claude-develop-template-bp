# Deploy スキル

このスキルはデプロイ手順の確認と実行を支援します。

## 使い方

`/deploy` コマンドで実行できます。

## 手順

1. **事前確認**
   - すべてのテストが通っていることを確認
   - main ブランチが最新であることを確認
   - 未コミットの変更がないことを確認

2. **ビルド**
   - プロジェクトのビルドコマンドを実行
   - ビルド成果物を確認

3. **デプロイ**
   - ステージング環境にデプロイ
   - 動作確認を実施
   - 問題なければ本番環境にデプロイ

4. **事後確認**
   - ヘルスチェックの実施
   - ログの監視
   - 問題発生時のロールバック手順を確認

## 注意事項

- 本番デプロイは必ず2名以上で確認すること
- デプロイ時間帯はチームで合意した時間帯に限定する
- ロールバック手順を事前に確認してからデプロイする
