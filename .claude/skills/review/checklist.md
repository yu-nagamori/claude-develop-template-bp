# コードレビューチェックリスト

## 機能性

- [ ] 要件を満たしているか
- [ ] エッジケースが考慮されているか
- [ ] エラーハンドリングが適切か

## コード品質

- [ ] コードスタイルガイドに準拠しているか
- [ ] 命名が適切か
- [ ] 不要なコード（デッドコード）がないか
- [ ] 重複コードがないか

## セキュリティ

- [ ] 入力値のバリデーションが行われているか
- [ ] 機密情報がハードコードされていないか
- [ ] SQLインジェクション・XSS等の脆弱性がないか

## テスト

- [ ] 新機能にテストが追加されているか
- [ ] 既存テストが壊れていないか
- [ ] テストケースが十分か

## パフォーマンス

- [ ] N+1問題がないか
- [ ] 不要なループや計算がないか
- [ ] メモリリークの可能性がないか

## ドキュメント

- [ ] 必要なコメントが記載されているか
- [ ] APIドキュメントが更新されているか
- [ ] CHANGELOGが更新されているか
